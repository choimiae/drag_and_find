# 뜻이 여러 개인 카드: 스크롤형 설명 목록

## 목적

뜻이 여러 개인 검색 결과를 한눈에 읽고 비교할 수 있게 한다. 현재의 알약형 뜻 버튼과 최대 8개 제한은 설명을 훑기 어렵고, 잘린 후보는 카드 안에서 확인할 수 없다.

## 확정한 화면 방향

- A형 설명 목록을 사용한다. 카드 폭은 현재처럼 320px이다.
- 각 항목은 뜻 이름과 한국어 설명을 세로로 보여 준다. 연결 문서가 있는 항목은 행을 눌러 해당 뜻의 상세 결과로 이동한다.
- 설명을 얻지 못한 항목은 제목 아래에 짧게 `간단한 설명이 없습니다.`라고 표시한다. 영어 설명으로 대신하지 않는다.
- 모든 뜻을 처음부터 목록에 넣는다. `외 N개`나 `더 보기` 버튼을 두지 않는다.
- 목록 영역만 카드 안에서 세로로 스크롤한다. 제목, 출처, 검색어 입력줄은 목록 밖에 둔다. 카드의 기존 화면 경계 안에서 목록 높이를 제한한다.
- 문맥 추천에 충분한 근거가 있으면 기존 추천 블록을 목록 위에 둔다. 추천 뜻은 목록에서 중복 표시하지 않는다. 근거가 부족하면 특정 뜻을 정답처럼 강조하지 않고 원래 순서대로 보여 준다.
- 기본 뜻 문장이 있으면 기존처럼 목록 앞에 표시한다.

## 출처 표시

- 출처는 카드에 **실제로 표시한 설명**을 기준으로 한다.
- 위키백과 뜻 목록이면 `위키백과 원문` 링크와 `CC BY-SA 4.0` 라이선스 링크를 표시한다. 짧게 옮기거나 가공한 설명임을 명확히 표시한다.
- 네이버 백과 설명을 보여 주는 결과에서는 `네이버 백과` 이름과 원문 링크를 표시한다. 네이버 결과를 위키백과 뜻 목록의 한 항목처럼 합치지 않는다.
- POC의 네이버 검색 결과는 이 글의 앱 개발 문맥과 다른 의료 용어이므로 위키백과 뜻 목록에 포함하거나 네이버를 출처로 적지 않는다.
- 위키데이터 설명을 보여 주는 결과에서는 위키데이터 원문과 CC0 링크를 유지한다.

## 동작과 예외

- 뜻 목록이 짧으면 스크롤바가 나타나지 않는다. 긴 목록은 카드 내부에서 끝까지 볼 수 있다.
- 설명이 없는 항목도 제목을 읽을 수 있고, 연결 문서 제목이 있으면 기존 방식으로 상세 결과를 조회한다.
- 상세 결과로 이동하면 그 결과의 실제 출처에 맞춰 링크와 표기를 다시 그린다.
- 검색어 입력 중인 값과 커서, 검색 버튼, 닫기, 다시 시도, 밝은/어두운 테마 동작을 유지한다.

## 검증

- 단위 테스트: 전체 후보 렌더링, 설명 유무, 추천 후보 중복 제거, 각 항목 클릭 대상, 실제 출처별 링크와 라이선스 표기.
- 브라우저 테스트: 8개를 넘는 뜻을 카드 안에서 마지막 항목까지 스크롤, 카드 제목과 검색 줄 유지, 항목 클릭 후 상세 결과 표시.
- 실제 기사 확인: POC 카드에서 설명 목록과 출처 링크를 확인한다.

## 검토 범위

이 문서는 카드의 정보 배치와 스크롤 동작만 다룬다. 검색 결과의 순서나 문맥 추천 알고리즘은 변경하지 않는다.
