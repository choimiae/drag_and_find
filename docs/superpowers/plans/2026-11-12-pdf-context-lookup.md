# PDF 우클릭 조회 구현 계획

**목표:** 기본 PDF 뷰어의 선택 글자를 우클릭 메뉴로 조회하고 사이드 패널에 표시한다.

**구조:** 백그라운드는 선택 메뉴를 등록하고 클릭 시 패널을 열며 탭별 임시 저장소에 글자를 기록한다. 패널은 저장소에서 글자를 읽고 기존 카드 렌더러와 조회 요청을 사용한다.

**기술:** WXT, Chrome contextMenus/sidePanel/storage.session, Vitest, Playwright.

1. 메뉴 클릭 처리의 실패 테스트를 작성하고 실행한다. 선택 글자 정리, 빈 글자 무시, 탭별 저장을 검증한다.
2. 메뉴 처리 모듈과 백그라운드 등록 코드를 작성하고 단위 테스트를 통과시킨다.
3. 패널의 실패 테스트를 작성하고 실행한다. 로딩·결과·길이 초과·재시도·다른 뜻을 검증한다.
4. WXT 사이드 패널 진입점과 기존 카드 재사용 화면을 작성한다. 테마와 탭별 임시 저장소 갱신을 연결한다.
5. README, PRIVACY, 스토어 설명에 PDF 사용법과 데이터 흐름을 추가한다.
6. `pnpm format:check`, `pnpm lint`, `pnpm compile`, `pnpm test`, `pnpm test:e2e`를 실행한다. 기본 PDF 뷰어의 실제 메뉴 표시는 별도로 확인한다.
