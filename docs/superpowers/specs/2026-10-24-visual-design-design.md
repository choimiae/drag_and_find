## 1. 목적

지금 카드·아이콘·설정 화면은 임시 모양이다. 뜻 모음 정보까지 들어가 카드가 복잡해졌으므로, 정보가 많아도 정돈돼 보이는 디자인으로 바꾸고 공개(웹스토어) 준비의 바탕을 만든다.

## 2. 결정 사항 (사용자와 확정)

| 항목 | 결정 |
|---|---|
| 카드 디자인 | **C(깔끔한 정보 카드)**: 흰 바탕, 위쪽 초록→파랑 색띠, "뜻 여러 개" 배지, G/N 표시가 있는 검색 버튼 |
| 카드 구성 | **B의 구성**: "이 글에서는 아마"는 연한 파랑 상자 안에 작은 표지와 함께, 다른 뜻은 알약 모양 태그, 검색 버튼은 아래 띠 |
| 테마 | 설정에서 **크롬 설정 따라가기(기본) / 밝게 / 어둡게** |
| 드래그 아이콘 | **B**: 초록→파랑 그라데이션 원 + 흰 돋보기 선(SVG). 이모지 사용 중단 |
| 설정 화면 | 카드와 같은 디자인. 테마 세 칸 선택, 아이콘 켜기 스위치, 단축키 표시 + 바꾸기 버튼 |
| 툴바 아이콘 | 드래그 아이콘과 같은 그라데이션 원 + 흰 돋보기. WXT 기본 아이콘 교체 |

사전 확인: 크롬 "설정 → 모양 → 모드"를 바꾸면 웹페이지의 `prefers-color-scheme` 값이 즉시 따라 바뀌는 것을 사용자 크롬에서 확인했다(2026-10-24). 크롬 테마의 **색**을 읽는 확장 기능은 없다.

## 5. 카드 구성

```
┌──────────────────────────────────┐  ← 4px 색띠
│ 트리거 [뜻 여러 개]           ✕  │
│ ┌──────────────────────────────┐ │
│ │이 글에서는 아마              │ │  ← 연한 파랑 상자 (suggestion 있을 때)
│ │데이터베이스 트리거           │ │     제목은 누를 수 있음
│ │테이블에 변경이 생기면 …      │ │
│ └──────────────────────────────┘ │
│ 기본 뜻                          │
│ 총의 방아쇠를 뜻하는 사격용어.   │
│ 다른 뜻                          │
│ (방아쇠) (트리거 (애니…)) [트리거 전략] 외 4개 │  ← 알약 태그 / 점선 태그(누를 수 없음)
│                  위키백과에서 보기 →│
├──────────────────────────────────┤
│ [G 구글 검색]   [N 네이버 검색]  │  ← 아래 띠
└──────────────────────────────────┘
```

- 카드 너비 320px, 모서리 12px
- "뜻 여러 개" 배지는 `isDisambiguation`일 때만
- 일반 단어 카드: 색띠 + 제목 + 요약 + 위키백과 링크 + 아래 띠 (배지 없음)
- 상태 카드(찾는 중, 없음, 막힘, 연결 실패, 너무 김)도 같은 틀
- 기존 `data-role` 이름은 모두 유지하고, 배지에 `data-role="badge"`를 추가한다
- 버튼·태그는 `:hover`·`:focus-visible` 모양을 갖는다

## 6. 테마

### 6.1 설정 데이터 (`lib/settings.ts`)
```ts
type ThemeSetting = 'auto' | 'light' | 'dark';
interface Settings { showIcon: boolean; theme: ThemeSetting }
DEFAULT_SETTINGS = { showIcon: true, theme: 'auto' }
```
- `parseSettings`: `theme`이 세 값 중 하나가 아니면 `'auto'`
- 기존에 저장된 `{ showIcon }`만 있는 값도 그대로 읽힌다(테마는 기본값)

### 6.2 카드에 반영
- 오버레이 호스트 요소에 `data-theme="auto|light|dark"` 속성을 둔다
- CSS: `:host`에 밝은 세트, `:host([data-theme="dark"])`에 어두운 세트, `@media (prefers-color-scheme: dark) { :host([data-theme="auto"]) { 어두운 세트 } }`
- `Overlay`에 `setTheme(theme: ThemeSetting): void` 추가
- 페이지 쪽은 시작할 때 설정을 읽어 `setTheme`을 부르고, `browser.storage.onChanged`로 설정이 바뀌면 다시 부른다(열린 탭에도 바로 반영)
- 설정 읽기에 실패하면(확장 업데이트 후 끊긴 탭 등) `'auto'` 그대로 둔다

### 6.3 설정 화면
- 설정 화면 자체는 크롬 모드를 따른다(`prefers-color-scheme`). 카드 테마 설정과는 별개
- 테마: 라디오 버튼 3개를 세 칸 선택 버튼 모양으로 꾸민다(`fieldset` + `legend`, 키보드로 고를 수 있음)
- 아이콘 켜기: 기존 체크박스를 스위치 모양으로 꾸민다(`role="switch"`)
- 저장 실패 시 직전 값으로 되돌리는 기존 규칙을 테마에도 적용한다

## 7. 아이콘

### 7.1 드래그 아이콘
- 28px 원, 그라데이션 바탕, 흰 돋보기 선 SVG(지름 14px)
- SVG는 `document.createElementNS`로 만든다(`innerHTML` 금지)
- 그림자 `0 3px 10px rgba(26,115,232,.35)`, `:hover`에서 살짝 커짐(transform), `:focus-visible` 테두리
- 어두운 페이지에서도 같은 모양(그라데이션이 양쪽 다 잘 보임)

### 7.2 확장 아이콘
- 원본: `assets/icon.svg` (그라데이션 원 + 흰 돋보기, 크기가 작을수록 선 굵게)
- PNG 16/32/48/96/128을 `public/icon/`에 생성해 커밋한다
- 생성은 저장소의 스크립트(`scripts/render-icons.mjs`, 이미 설치된 Playwright Chromium으로 SVG를 PNG로 찍음)로 하고, 명령을 `CLAUDE.md`에 적는다. 빌드 때마다 돌리지는 않는다

## 8. 테스트

### 단위
- `parseSettings`: 테마 세 값, 잘못된 값 → `'auto'`, 테마 없는 예전 값
- 설정 화면: 저장된 테마 표시, 테마 바꾸면 저장, 저장 실패 시 되돌림, 스위치 `aria-checked` 동기화
- 오버레이: `setTheme`이 호스트 `data-theme`을 바꿈, 아이콘이 SVG를 담고 이모지 글자가 없음
- 카드: 배지가 뜻 모음에서만 보임, 기존 `data-role` 유지, 외부 글자 `textContent`
- 페이지 쪽: 시작 시 테마 적용, 저장소 변경 시 다시 적용, 읽기 실패 시 `'auto'`

### E2E
- 설정 화면에서 "어둡게" 선택 → 기사 탭(새로 열지 않고)에서 카드를 띄우면 호스트 `data-theme="dark"`
- 기존 E2E 9개 유지

### 수동 확인 (사용자)
- 밝은/어두운 크롬 모드, 밝은/어두운 블로그에서 카드·아이콘이 잘 보이는지
- 툴바 아이콘이 16px에서도 알아볼 수 있는지
