```
Drag and Find
```

**한 줄 설명 (132자 이하)**

```
모르는 단어를 드래그하면 네이버 백과 결과를 먼저, 없으면 위키백과 설명을 그 자리에서 보여 줍니다.
```

## 자세한 설명

```
모르는 단어가 나오면 검색창을 열지 말고, 그냥 드래그하세요.

Drag and Find는 웹페이지에서 드래그한 단어의 네이버 백과 검색 결과를 먼저 보여 주는 확장 프로그램입니다. 결과가 없거나 호출 한도를 넘으면 한국어 위키백과를 조회합니다.

[사용 방법]
1. 웹페이지에서 궁금한 단어를 드래그합니다.
2. 단어 옆에 나타난 돋보기 아이콘을 누르거나, 단축키 Alt+Shift+F(맥은 ⌥⇧F)를 누릅니다.
3. 출처가 표시된 설명 카드가 단어 아래에 나타납니다. Esc 키나 카드 바깥을 누르면 닫힙니다.

[주요 기능]
- 네이버 백과 우선 조회: 결과가 없거나 호출 한도를 넘으면 위키백과 요약으로 넘어갑니다.
- 뜻이 여러 개인 단어: 앞뒤 글을 보고 "이 글에서는 아마 이 뜻"을 먼저 골라 보여 주고, 기본 뜻과 다른 뜻도 함께 보여 줍니다. 다른 뜻을 누르면 그 뜻의 요약으로 바뀝니다.
- 구글·네이버 검색: 위키백과에 없거나 더 찾아보고 싶을 때, 같은 단어로 검색한 새 탭을 엽니다. 카드의 검색어 칸에서 검색어를 고쳐 검색할 수 있고, Enter를 누르면 설정에서 고른 사이트(기본 네이버)로 검색합니다.
- 설정: 드래그할 때 아이콘 표시 여부, 카드 테마(크롬 설정 따라가기 / 밝게 / 어둡게), Enter로 검색할 곳(네이버 / 구글)을 고를 수 있습니다.

[알아 두세요]
- 카드에 실제 출처와 원문 링크를 표시합니다. 위키백과 결과에는 CC BY-SA 4.0 표시를 붙입니다.

[개인정보]
- 찾기를 요청했을 때만 선택한 단어를 Cloudflare Worker로 보내며, Worker가 네이버 백과 또는 위키백과를 조회합니다.
- 구글·네이버 버튼은 내가 누를 때(또는 검색어 칸에서 Enter를 칠 때)만 동작합니다. 누르면 선택한 단어(또는 내가 고친 검색어)로 검색한 구글 또는 네이버 페이지가 새 탭으로 열리므로, 그 단어가 해당 사이트에 전달됩니다. 이후는 각 사이트의 정책을 따릅니다.
- 선택한 단어 앞뒤의 글은 뜻을 고르는 데에만 브라우저 안에서 쓰고, 어떤 서버에도 보내지 않습니다.
- 분석 도구와 광고는 없습니다. 설정은 내 기기에만 저장되고 검색 결과는 캐시하지 않습니다.
- 자세한 내용: https://github.com/choimiae/drag_and_find/blob/main/PRIVACY.md
```

## 개인정보 보호 탭

**단일 목적 설명 (Single purpose)**

```
웹페이지에서 사용자가 선택한 단어의 네이버 백과 또는 위키백과 설명을 그 자리에 카드로 보여 주어 단어의 뜻을 확인하게 한다.
```

**권한 사용 이유**

`storage`

```
사용자 설정(드래그 시 아이콘 표시 여부, 카드 테마, Enter로 검색할 곳)을 기기에 저장하는 데 사용합니다. 검색어와 결과는 저장하지 않습니다.
```

호스트 권한 `https://<배포된 Worker 주소>/*`

```
사용자가 아이콘이나 단축키로 찾기를 요청했을 때 선택한 단어를 Cloudflare Worker로 보내기 위해 필요합니다. Worker는 네이버 백과를 우선 조회하고 결과가 없거나 한도를 넘으면 위키백과를 조회합니다. 실제 배포한 Worker 주소를 적으세요.
```

모든 사이트에서 실행되는 콘텐츠 스크립트 (`<all_urls>`, 모든 프레임)

```
사용자가 어느 웹페이지에서든 단어를 드래그했을 때 선택을 감지하고 설명 카드를 표시하기 위해 필요합니다. 찾기를 요청했을 때만 선택한 단어(최대 50자)를 중계 Worker로 보냅니다. 앞뒤 글은 확장 내부에서만 사용하며 서버로 보내지 않습니다.
```

**원격 코드 사용**: 사용하지 않음

```
사용하지 않음. 실행 코드는 확장 프로그램 패키지에 포함되어 있으며 중계 Worker에서는 데이터(JSON)만 받습니다.
```

**데이터 사용 (Data usage)**

- 체크할 데이터 유형 후보: **웹사이트 콘텐츠**. 사용자가 선택한 글이 중계 Worker를 통해 네이버 백과 또는 위키백과에 전송됩니다. 대시보드의 최신 항목별 설명을 확인하세요.
- 인증 문항 세 가지는 모두 체크합니다.
  1. 승인된 사용 사례를 제외하고 사용자 데이터를 제3자에게 판매하지 않는다.
  2. 항목의 단일 목적과 관련 없는 목적으로 사용자 데이터를 사용하거나 전송하지 않는다.
  3. 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않는다.
