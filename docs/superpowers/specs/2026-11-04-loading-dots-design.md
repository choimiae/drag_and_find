# 뜻 보기 로딩 점 애니메이션 설계

## 결정

사용자가 선택한 B안을 적용한다. 카드의 제목·닫기 버튼·`뜻 보기 | 직접 찾기` 탭은 그대로 두고, 뜻 보기 본문의 `찾는 중…` 텍스트를 순서대로 움직이는 작은 점 세 개와 `뜻을 찾고 있어요` 문구로 바꾼다. 점은 확장의 파랑·청록·초록 색을 사용한다.

## 동작

- 최초 조회, 직접 찾기, 다시 시도, 뜻 상세 조회에서 같은 로딩을 표시한다.
- 점은 장식이므로 화면 읽기 도구에는 숨긴다. 로딩 문구는 상태로 알리고 결과로 바뀌면 사라진다.
- 운영체제에서 움직임 줄이기를 설정하면 점의 움직임을 멈춘다.
- 로딩 중에도 닫기와 탭 전환, 직접 찾기 입력 동작은 유지한다. 조회 결과·오류·출처 표시는 바꾸지 않는다.

## 확인

- 카드 단위 테스트에서 문구·점 구조·상태 접근성을 확인한다.
- Chromium E2E에서 조회 중 로딩이 보이고 결과가 오면 사라지는지 확인한다.
- 포맷·린트·타입 검사, 전체 단위·E2E 테스트를 실행한다.
- UI 확정 후 화면 확인용 임시 HTML은 삭제한다.
