# 웹스토어 등록 정보 (복사해서 붙여넣기용)

크롬 웹스토어 개발자 대시보드의 각 칸에 아래 내용을 그대로 붙여넣으면 됩니다. 대시보드 화면 구성은 바뀔 수 있으니 칸 이름이 조금 달라도 뜻이 같은 칸에 넣어 주세요.

## 기본 정보

**항목 이름**

```
Drag and Find
```

**한 줄 설명 (132자 이하)**

```
모르는 단어를 드래그하고 아이콘이나 Alt+Shift+F를 누르면 위키백과 요약을 그 자리에서 바로 보여 줍니다.
```

**언어**: 한국어

**카테고리**: 대시보드의 드롭다운에서 가장 가까운 항목을 고르세요. "생산성(Productivity)" 계열의 도구나 교육 쪽 항목이 어울립니다. 정확한 항목 이름은 대시보드에서 확인해 주세요.

## 자세한 설명

```
모르는 단어가 나오면 검색창을 열지 말고, 그냥 드래그하세요.

Drag and Find는 웹페이지에서 드래그한 단어의 한국어 위키백과 요약을 그 자리에 카드로 보여 주는 확장 프로그램입니다. 탭을 옮기지 않아도 읽던 흐름이 끊기지 않습니다.

[사용 방법]
1. 웹페이지에서 궁금한 단어를 드래그합니다.
2. 단어 옆에 나타난 돋보기 아이콘을 누르거나, 단축키 Alt+Shift+F(맥은 ⌥⇧F)를 누릅니다.
3. 위키백과 요약 카드가 단어 아래에 나타납니다. Esc 키나 카드 바깥을 누르면 닫힙니다.

[주요 기능]
- 위키백과 요약 보기: 한국어 위키백과의 첫 문단을 바로 보여 줍니다.
- 뜻이 여러 개인 단어: 앞뒤 글을 보고 "이 글에서는 아마 이 뜻"을 먼저 골라 보여 주고, 기본 뜻과 다른 뜻도 함께 보여 줍니다. 다른 뜻을 누르면 그 뜻의 요약으로 바뀝니다.
- 구글·네이버 검색 버튼: 위키백과에 없거나 더 찾아보고 싶을 때, 같은 단어로 검색한 새 탭을 엽니다.
- 설정: 드래그할 때 아이콘 표시 여부, 카드 테마(크롬 설정 따라가기 / 밝게 / 어둡게)를 고를 수 있습니다.

[알아 두세요]
- 한국어 위키백과만 사용합니다.
- 카드의 내용은 위키백과에서 가져오며, 출처와 라이선스(CC BY-SA 4.0)를 카드에 표시합니다.

[개인정보]
- 확장 프로그램이 자동으로 보내는 곳은 한국어 위키백과뿐이며, 아이콘이나 단축키로 찾기를 요청했을 때만 선택한 단어를 보냅니다.
- 구글·네이버 버튼은 내가 누를 때만 동작합니다. 누르면 선택한 단어로 검색한 구글 또는 네이버 페이지가 새 탭으로 열리므로, 그 단어가 해당 사이트에 전달됩니다. 이후는 각 사이트의 정책을 따릅니다.
- 선택한 단어 앞뒤의 글은 뜻을 고르는 데에만 브라우저 안에서 쓰고, 어떤 서버에도 보내지 않습니다.
- 분석 도구, 광고, 자체 서버가 없습니다. 설정은 내 기기에만 저장됩니다.
- 자세한 내용: https://github.com/choimiae/drag_and_find/blob/main/PRIVACY.md
```

## 개인정보 보호 탭

**단일 목적 설명 (Single purpose)**

```
웹페이지에서 사용자가 선택한 단어의 한국어 위키백과 요약을 그 자리에 카드로 보여 주어, 다른 탭으로 이동하지 않고 단어의 뜻을 확인하게 한다.
```

**권한 사용 이유**

`storage`

```
사용자 설정(드래그 시 아이콘 표시 여부, 카드 테마)을 기기에 저장하고, 방금 찾은 결과를 같은 브라우저 세션 동안 임시로 보관해 반복 요청을 줄이는 데 사용합니다. 브라우저를 닫으면 임시 결과는 사라집니다.
```

호스트 권한 `https://ko.wikipedia.org/*`

```
사용자가 아이콘이나 단축키로 찾기를 요청했을 때, 선택한 단어의 요약을 한국어 위키백과 공개 API에서 가져오기 위해 필요합니다. 이 주소 외의 서버에는 요청하지 않습니다.
```

모든 사이트에서 실행되는 콘텐츠 스크립트 (`<all_urls>`, 모든 프레임)

```
사용자가 어느 웹페이지에서든 단어를 드래그했을 때 선택을 감지해 아이콘을 보여 주고, 요약 카드를 그 페이지 위에 표시하기 위해 필요합니다. 페이지 내용을 읽어 저장하거나 전송하지 않습니다. 사용자가 찾기를 요청했을 때에 한해 선택한 단어(최대 50자)와, 알맞은 뜻을 고르기 위한 앞뒤 글(최대 250자)만 확장 프로그램 내부로 전달하며, 확장 프로그램이 직접 서버로 보내는 것은 요청 시 선택한 단어를 한국어 위키백과로 보내는 것뿐입니다. 구글·네이버 버튼은 사용자가 고른 검색 페이지를 새 탭으로 열 뿐입니다.
```

**원격 코드 사용**: 사용하지 않음

```
사용하지 않음. 모든 코드는 확장 프로그램 패키지에 포함되어 있으며, 외부에서 코드를 내려받거나 실행하지 않습니다. (위키백과에서는 데이터(JSON)만 받습니다.)
```

**데이터 사용 (Data usage)**

- 체크할 데이터 유형 후보: **웹사이트 콘텐츠**. 사용자가 선택한 글(웹페이지의 텍스트)이 검색어로서 위키백과에 전송되기 때문입니다. 사용자가 구글·네이버 버튼을 눌러 같은 글이 해당 검색 페이지 주소에 담기는 경우도 있으니, 대시보드의 설명에서 이런 경우를 어떻게 다루라고 하는지 함께 확인해 주세요. 대시보드의 항목별 설명을 읽고, 선택한 글이 어디에 해당하는지 직접 한 번 더 확인해 주세요. 그 외 항목(개인 식별 정보, 건강, 금융, 인증, 위치, 웹 기록, 사용자 활동 등)은 수집하지 않으므로 체크하지 않습니다.
- 인증 문항 세 가지는 모두 체크합니다.
  1. 승인된 사용 사례를 제외하고 사용자 데이터를 제3자에게 판매하지 않는다.
  2. 항목의 단일 목적과 관련 없는 목적으로 사용자 데이터를 사용하거나 전송하지 않는다.
  3. 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않는다.
