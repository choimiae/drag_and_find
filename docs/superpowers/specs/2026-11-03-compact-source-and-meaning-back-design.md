# 출처 한 줄 표시와 뜻 목록 돌아가기 설계

## 목적

설명 카드에서 주 출처와 다른 출처의 원문 링크를 한눈에 읽을 수 있게 정리하고, 여러 뜻 중 하나의 상세 설명을 연 뒤 원래 뜻 목록으로 돌아갈 수 있게 한다.

## 선택한 화면

네이버 백과 설명과 위키백과 대안이 함께 있으면 요약 아래에 얇은 구분선으로 시작하는 한 줄을 둔다.

`원문　네이버 백과 ↗　│　위키백과 ↗`

두 링크는 기존처럼 각각 해당 원문 문서를 새 탭에서 연다. 출처별 큰 버튼이나 펼침 메뉴는 사용하지 않는다. 출처가 하나면 같은 줄에 해당 링크만 표시한다. 카드 폭이 좁으면 링크가 다음 줄로 자연스럽게 넘어가며 글자를 잘라 숨기지 않는다. 기존 출처 및 라이선스 표기는 아래에 유지한다. 뜻 모음 결과에서 원문 링크 하나가 카드 아래쪽에 고정되는 현재 위치도 유지하되 같은 한 줄 스타일을 쓴다.

뜻 목록에서 항목을 누르면 현재처럼 그 항목을 조회해 카드 안에 상세 설명을 표시한다. 상세 화면의 헤더 왼쪽에는 `← 뜻 목록` 버튼을, 본문 맨 위에는 상세 문서 제목을 표시한다. 버튼을 누르면 처음 열었던 뜻 목록으로 돌아가고, 카드 본문과 뜻 목록 각각의 스크롤 위치를 복원한다. 뒤로 가기는 저장한 결과를 다시 그리므로 API를 재호출하지 않는다. 상세 조회가 로딩 중이거나 실패했어도 버튼을 사용할 수 있다. 다른 단어를 새로 선택해 조회하거나 카드를 닫으면 돌아갈 목록을 지운다. 상세 화면에서 또 다른 뜻을 열어도 버튼은 최초 뜻 목록으로 돌아간다.

## 구성 요소

- `lib/ui/card.ts`: 주 출처와 대안 링크를 하나의 출처 줄로 렌더링하고, 상세 화면의 헤더에 돌아가기 버튼을 넣는다. 링크의 URL 검증과 출처·라이선스 표기 규칙은 현재 코드를 따른다.
- `lib/ui/styles.ts`: 320px 카드 폭에서도 읽히는 작은 출처 줄과 헤더 돌아가기 버튼을 정의한다.
- `lib/content/controller.ts`: 첫 뜻 목록의 검색어·결과·문맥·스크롤 위치를 저장하고, 돌아갈 때 서버 요청 없이 복원한다. 새 단어 조회와 카드 닫기에는 저장 상태를 비운다.
- `lib/ui/overlay.ts`: 카드 본문과 뜻 목록의 스크롤 위치를 읽고 복원하는 좁은 인터페이스를 제공한다.

## 검증

- 주 출처와 대안 출처가 있으면 한 줄의 출처 영역에 순서대로 표시되고 각각의 원문 URL이 유지된다.
- 출처가 하나면 링크가 하나만 보이며, 좁은 카드에서도 내용이 잘리지 않는다.
- 뜻 항목을 열면 `← 뜻 목록`이 나타나고, 클릭 시 원래 목록·검색어·스크롤 위치가 복원되며 추가 조회가 없다.
- 상세 조회가 실패하거나 진행 중일 때도 목록으로 돌아갈 수 있고, 늦게 도착한 상세 결과가 복원한 목록을 덮지 않는다.
- 새 선택과 닫기 이후에는 이전 목록으로 돌아가는 버튼이 나타나지 않는다.
- 단위 테스트, E2E, 타입 검사, 린트, 배포 빌드로 회귀를 확인한다.
