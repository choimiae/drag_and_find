# 공개 요청과 외부 링크 보완 설계

- 작성일: 2026-11-12
- 범위: 조회 Worker의 공개 POST 경로, 카드의 원문 링크, 개발 의존성

## 요청 본문

`/english-context`와 `/telemetry`는 기존 JSON 형식과 오류 응답을 유지한다. IP별 요청 제한을 본문 읽기 전에 적용한다. 본문은 스트림에서 읽으면서 각각 4,000바이트와 500바이트를 넘는 즉시 읽기를 중단하고 400을 반환한다. `Content-Length`가 한도를 넘으면 읽기 전에 거부하되, 이 헤더가 없거나 틀려도 스트림 제한이 작동해야 한다. 설정되지 않은 `RATE_LIMITER`는 기존처럼 허용한다.

## 원문 링크

네이버 결과는 `terms.naver.com`, 위키백과 결과는 `ko.wikipedia.org` 또는 `en.wikipedia.org`, 위키데이터 결과는 `www.wikidata.org`의 HTTPS URL만 원문 링크로 사용한다. 사용자 정보가 URL에 포함되면 거부한다. 기본 링크, 대체 출처, 관련 문서 링크에 같은 규칙을 적용하고 거부된 링크는 클릭할 수 없게 표시한다. 네이버 API 응답 단계에서도 허용되지 않은 링크를 결과에서 제외한다. 검색 엔진 링크와 라이선스 링크는 기존 동작을 유지한다.

## 의존성과 검증

`minimatch` 보안 권고가 사라지도록 호환되는 개발 의존성 버전을 선택한다. 잠금 파일을 갱신한 뒤 전체 감사와 저장소 검증 명령을 실행한다. 배포와 커밋은 이번 작업에 포함하지 않는다.
