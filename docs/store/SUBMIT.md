# 크롬 웹스토어 제출 가이드

처음 한 번만 하는 일(1)과, 올릴 때마다 하는 일(2~9)로 나뉩니다. 대시보드 화면은 바뀔 수 있어서 버튼 이름은 대략적으로 적었습니다.

## 1. 개발자 계정 만들기 (처음 한 번)

1. https://chrome.google.com/webstore/devconsole 에 구글 계정으로 로그인합니다.
2. 개발자 약관에 동의하고, 일회성 등록 수수료를 결제합니다. 금액은 결제 화면에 표시되는 값을 확인하세요.
3. 등록 정보 입력 중에 "트레이더(판매자)" 여부를 묻는 항목이 있으면, 무료로 배포하는 개인 확장이므로 비트레이더를 고릅니다. 대한민국은 지원 국가 목록에 있습니다. 이름·주소 등은 실제 정보를 입력하세요.
4. 연락처 이메일 인증이 필요하면 안내에 따라 마칩니다.

## 2. 올릴 파일 만들기

터미널에서 저장소 폴더로 가서 실행합니다.

```
pnpm install
pnpm zip
```

zip 파일은 `.output/` 폴더에 `drag-and-find-1.0.0-chrome.zip` 같은 이름으로 생깁니다(버전이 이름에 들어갑니다).

## 3. 새 항목 만들고 올리기

1. 대시보드에서 새 항목을 추가하는 버튼을 누릅니다.
2. 2번에서 만든 zip 파일을 올립니다.
3. 올리면 항목 편집 화면으로 넘어갑니다. 이름, 버전, 아이콘은 패키지 안의 매니페스트에서 채워집니다.

## 4. 스토어 등록정보 채우기

`docs/store/listing.md`의 "기본 정보"와 "자세한 설명"을 각 칸에 붙여넣습니다. 이어서 `docs/store/images/` 폴더의 파일을 올립니다.

- 스크린샷: `screenshot-1.png` ~ `screenshot-4.png`
- 작은 홍보 이미지: `promo-small.png`
- 카테고리와 언어(한국어)를 고르고, 홈페이지·지원 URL을 입력합니다.

## 5. 개인정보 보호 탭 채우기

`listing.md`의 "개인정보 보호 탭"을 순서대로 입력합니다.

- 단일 목적 설명
- 권한별 사용 이유
- 원격 코드 사용 여부
- 데이터 사용 항목과 인증 문항 (항목 이름은 대시보드의 설명을 읽고 한 번 더 확인하세요)
- 개인정보처리방침 URL

## 6. 배포 설정

배포 범위는 "공개"로, 지역은 모든 지역으로 설정합니다.

## 7. 심사 제출

1. 비어 있는 필수 항목이 없는지 대시보드의 안내를 확인합니다.
2. 심사 제출 버튼을 누릅니다.
3. 새 개발자 계정이거나 모든 사이트에서 동작하는 권한(`<all_urls>`)을 쓰는 확장은 심사가 평소보다 오래 걸릴 수 있습니다. 며칠에서 길게는 몇 주까지 걸릴 수 있다고 생각하고 기다리세요. 결과는 이메일로 옵니다.
4. 반려되면 이메일에 적힌 이유를 읽고, 항목 정보나 권한 설명을 고쳐서 다시 제출합니다.

## 8. 승인 후

1. 대시보드에서 항목의 스토어 링크(주소)를 복사합니다.
2. 그 링크를 사람들에게 공유합니다.

## 9. 나중에 업데이트하기

1. `package.json`의 `version`을 올립니다. 예: `1.0.0` → `1.0.1` (이전보다 커야 합니다).
2. `pnpm zip`으로 새 zip을 만듭니다.
3. 대시보드의 해당 항목에서 새 패키지를 올리는 메뉴로 새 zip을 올리고, 심사에 제출합니다.
4. 카드 모양이 바뀌었다면 `pnpm store:images`로 스크린샷을 다시 만들어 바꿔 올립니다.
