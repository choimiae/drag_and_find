# PDF 우클릭 조회 설계

Chrome 기본 PDF 뷰어에서 글자를 선택한 뒤 우클릭 메뉴의 `Drag and Find로 찾기`를 누르면 사이드 패널에 뜻을 표시한다. 같은 메뉴는 일반 웹페이지의 선택 글자에도 표시된다. PDF 뷰어 내부에 콘텐츠 스크립트나 카드를 삽입하지 않는다.

- 확장은 `contextMenus`, `sidePanel`, 기존 `storage` 권한을 사용한다. 선택 메뉴는 설치와 업데이트 시 등록한다.
- 메뉴 클릭 직후 패널을 열고 선택 글자를 탭별 `storage.session`에 보관한다. 패널은 현재 탭의 글자를 읽고 변경을 구독한다.
- 패널은 기존 `checkSelection`, 조회 메시지, `renderCard`를 재사용한다. 최대 50자 제한, 출처 링크, 재시도, 다른 뜻 탐색은 유지한다.
- PDF 파일 내용과 URL은 저장하거나 조회 서버에 보내지 않는다. 선택한 글자만 사용자의 메뉴 클릭 후 기존 조회 경로로 보낸다.
- 선택 가능한 텍스트가 없는 PDF와 복사가 제한된 PDF에서는 메뉴가 표시되지 않을 수 있다. Chrome PDF 뷰어에서의 실제 메뉴 표시는 브라우저 수동 확인 대상으로 둔다.
- 단위 테스트로 메뉴 클릭 처리와 패널 카드 상태를 검증한다. 브라우저 동작을 바꾸므로 기존 E2E도 실행한다.
